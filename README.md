
# RAG Document Question Answering System

## Description
A Retrieval Augmented Generation (RAG) application that allows users to upload PDF/TXT documents and ask questions using Cohere LLM.

## Features
- Document upload
- Text chunking
- Sentence Transformer embeddings
- Semantic search
- Cohere AI answer generation

## Technologies
- Python
- Streamlit
- LangChain
- Cohere API
- Sentence Transformers

## Run Application

Install dependencies:

pip install -r requirements.txt

Run:

streamlit run app.py
